## Instructions from the source

1. State the outcome and constraints; ask the agent to challenge a substantial plan before building. [21:17](https://www.youtube.com/watch?v=xJaMTo2YgO8&t=1277s)
2. Read its reasoning, answer objections, and correct misunderstandings. Request a response format you will actually read. [24:01](https://www.youtube.com/watch?v=xJaMTo2YgO8&t=1441s)
3. Put recurring project intent and ambiguous domain terms in AGENTS.md. [27:00](https://www.youtube.com/watch?v=xJaMTo2YgO8&t=1620s), [33:21](https://www.youtube.com/watch?v=xJaMTo2YgO8&t=2001s)
4. Start a fresh conversation for a different concern. For complex requests, provide a concrete example, desired behavior, and constraints; ask for missing cost details. [35:08](https://www.youtube.com/watch?v=xJaMTo2YgO8&t=2108s), [37:19](https://www.youtube.com/watch?v=xJaMTo2YgO8&t=2239s)
5. Review the resulting plan, then give the implementing agent tests, CLI tools, or browser access to verify the outcome. [39:04](https://www.youtube.com/watch?v=xJaMTo2YgO8&t=2344s)
