# Domain documentation

This repository uses one domain context. Read [CONTEXT.md](../../CONTEXT.md) for vocabulary and [the current architecture decision](../adr/0051-current-architecture.md) before changing domain behavior. Use [the handoff](../handoff.md) for unresolved proposals, not as authorization to implement them.

Use the glossary's terms consistently. When an accepted decision needs changing, identify the conflict and update its documentation alongside the implementation. New decisions belong under `docs/adr/`; keep historical/superseded material in Git rather than presenting conflicting instructions as current.
