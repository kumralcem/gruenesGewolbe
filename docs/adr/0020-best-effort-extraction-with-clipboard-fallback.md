# Best-Effort Extraction With Clipboard Fallback

The app should attempt limited best-effort extraction from sources such as X.com, but it should not depend on logged-in scraping, bypassing platform restrictions, or archiving surrounding discussion. When extraction fails, the fallback should accept a structured manual bundle such as source URL, saving reason, copied image, and copied post or page text, preserving the user's intent without requiring file downloads and attachments.
