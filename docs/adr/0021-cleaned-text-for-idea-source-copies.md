# Cleaned Text for Idea Source Copies

Idea captures should preserve cleaned text as the primary source copy rather than requiring raw HTML, screenshots, or replayable page archives. The cleaned text should keep the full main content when available, removing page noise without letting AI or extraction heuristics discard relevant body text. Raw HTML may be kept when cheap and useful, but the durable record should favor readable main content plus summary, saving reason, tags, and source link because those are what make the item actionable later.
